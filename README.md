This repository contains my data analysis and visualization projects created using datasets from the [TidyTuesday](https://github.com/rfordatascience/tidytuesday)
Each week a new dataset is published with a new challenge or task to take on. This is where I am housing all of my projects relating to these datasets.
I enjoy doing data exploration, visualization, and statistical modeling. Each unique week will be getting its own folder to help structure the project.
For the most part I stick with scripts but some weeks I will work in Quarto documents.
